The import pipeline previously wrote every sheet as an independent table, so a workbook with lookups between sheets lost those lookups. The change records the relationship at parse time, stores it beside the table, and the preview shows which columns became links.

How it works

  1. Workbook uploaded apps/web/import/Upload.tsx:41
    The file goes to the import service unchanged; nothing is parsed in the browser.
  2. Parse records relationships services/import/parse/relations.ts:22
    Each cross-sheet formula becomes a Relation {fromSheet, fromColumn, toSheet, toKey}. Formulas that reference a sheet outside the workbook are skipped and counted.
  3. Store beside the table services/import/store/relations.ts:58
    Relations are written in the same transaction as the table rows, keyed by (tenant_id, import_id, from_sheet, from_column), so a retry upserts instead of duplicating.
  4. Preview marks link columns apps/web/import/Preview.tsx:103
    Columns with a relation get a link icon and a tooltip naming the target sheet.
services/import/store/relations.tslines 58–71
export async function upsertRelations(tx, importId, rels) {
  // Keyed on the source cell, so a retried import updates rather than duplicates.
  for (const r of rels) {
    await tx.relations.upsert({
      where: { tenantId_importId_fromSheet_fromColumn: key(tx.tenantId, importId, r) },
      update: { toSheet: r.toSheet, toKey: r.toKey },
      create: { ...r, importId, tenantId: tx.tenantId },
    });
  }
}
